## Getting Started

1. Download an official Systemcore image, **version 13 or newer**, from the
   [systemcore-os-public releases](https://github.com/LimelightVision/systemcore-os-public/releases)
   (the beta `limelightsystemcorebetacm5-...zip`)
2. Unzip the image
3. Using raspberry pi imager or balena etcher to burn the image to an SD card
4. Put SD Card into the pi and boot
5. Connect to the SYSTEMCORE wifi that is generated by the PI
6. open an browser and navigate to either 172.30.0.1 or robot.local
7. Copy this `no-fd` folder to the pi and run `sudo ./install.sh` from
   `systemcore-can-nofd-setup` — see [its README](./systemcore-can-nofd-setup/README.md),
   or the [New Build Guide](../setup/New%20Build.md) for the whole walkthrough
8. YOUR IN!
