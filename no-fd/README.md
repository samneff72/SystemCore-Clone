A simple project using a Raspberry Pi with a Waveshare CAN Pi HAT.

  https://www.amazon.com/dp/B0FL21867J?ref=ppx_yo2ov_dt_b_fed_asin_title&th=1

- **Waveshare CAN Pi HAT:**  
  https://www.amazon.com/dp/B087RJ6XGG?ref=ppx_yo2ov_dt_b_fed_asin_title

## Bobcat SystemCore Image

Preconfigured config.txt and added the the service to add the overlay and "direct" can data to the overlay.
(Built from SystemCore image 12. For image 13 or newer, install the overlay below onto the official image instead.)

## Getting Started

1. Download the systemcore-can-nofd.img.zip
2. Unzip the image
3. Using raspberry pi imager or balena etcher to burn the image to an SD card
4. Put SD Card into the pi and boot
5. Boot the raspberry pi
6. Connect to the SYSTEMCORE wifi that is generated by the PI
7. open an browser and navigate to either 172.30.0.1 or robot.local
7. YOUR IN!

For image 13 or newer: flash the official image and follow [systemcore-can-nofd-setup/README.md](./systemcore-can-nofd-setup/README.md).
